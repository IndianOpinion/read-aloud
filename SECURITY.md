# Security policy

## Reporting a vulnerability

Please email hello@indianopinion.org with a description, the affected version
and steps to reproduce. Do not open a public issue for a security problem.

We acknowledge reports within 3 working days and aim to ship a fix or a
mitigation within 30 days, sooner for anything that leaks keys or post text,
lets a reader reach unpublished text, or lets a provider write executable
files. We credit reporters in the release notes unless you ask us not to.

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
